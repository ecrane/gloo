# Gloo — Core Interpreter

The gloo language interpreter, packaged as a Ruby gem.

Source layout, how to run both test suites (`rake test` and `ruby lib/run.rb --test --quiet test.gloo/` — not `bundle exec`), documentation conventions and the error-reporting rule are in the development guide:

@docs/development.md

This project is the authoritative source for gloo language documentation: the narrative pages in `docs/` and the `doc_data` on each verb and object class.
